6 # Build a user story
7
8 You are working on the issue named in the prompt. The repo is already cloned
9 and checked out at `main`. Work only in this repository.
10
11 ## Steps
12
13 1. Read the issue and every comment: `gh issue view <n> --comments`.
14 2. Create a branch `ad/<n>-<short-slug>` from `main`.
15 3. Implement the change. Follow `CONTRIBUTING.md` and existing patterns.
16 4. Run `dotnet build` and `dotnet test`. Fix failures before you go on.
17+5. Run `dotnet format --verify-no-changes` and fix what it reports.
18 6. Push, then open a PR with `gh pr create`. Start the body with `Closes #<n>`.
19 7. Comment `/code-review` on the PR. This starts the review run.
20
21 ## Rules
22
23 - Never push to `main`.
24 - If the issue is ambiguous, ask in the terminal and wait for an answer.
25 - Keep the PR under 400 changed lines; split the work if it grows.
