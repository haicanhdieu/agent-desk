Agent Desk

Proof-of-concept screens

A developer delegates GitHub tickets to Claude Code runs. GitHub stays the board; Agent Desk adds routing rules, one container per run, and the live terminal. Each artboard on this canvas is one screen or state. Click a name to jump to it, or comment on any element.

Run status, one shape per state

Colour always comes with a distinct icon and a word. Amber is reserved for runs that need you.

QueuedWaiting for a free slot
StartingPod scheduled, cloning, launching
RunningAgent is working on its turn
Needs youAgent finished its turn and waits for you (status idle)
SucceededEnded normally, by Finish or idle timeout
FailedAgent exited non-zero or pod failed
Timed outHit the run time limit
CancelledStopped by you
